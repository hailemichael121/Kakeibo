About the checksum manifest

The manifest contains one line for every downloadable build on this page. It is the standard sha256sum format: a 64-character SHA-256 fingerprint, two spaces, then the filename. Download SHA256SUMS and keep it next to your downloaded files.

From that folder, run sha256sum -c SHA256SUMS on Linux, or shasum -a 256 -c SHA256SUMS on macOS. Every line should end in OK. If a fingerprint differs, delete the file and download it again.

The macOS build is not published yet, so it is not listed. It will be added to the manifest when it ships.
